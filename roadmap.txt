**Обзор структуры / Дорожная карта TitanBot**

**Цель**

* Сохранить это как практическую карту кодовой базы.

**Корневой каталог (Root)**

* scripts/                    -> утилиты/скрипты обслуживания (создание бэкапов, восстановление, миграция)

**Функции веб-панели управления (Web Dashboard)**

* Темный дизайн (цветовая схема zinc-950, slate-800)
* Боковая панель навигации с выбором сервера
* Верхняя панель с "хлебными крошками" и статусом API
* Страница обзора с карточками статистики
* Графики активности с интеграцией recharts
* Страницы настроек, модулей и команд (в скором времени)
* Кэширование Redis для быстрой загрузки данных
* Интеграция Discord OAuth2 для аутентификации

**Уровень абстракции базы данных**

* Поддерживает PostgreSQL (основная) с резервным хранилищем в оперативной памяти (in-memory) для разработки
* Слой кэширования Redis для оптимизации производительности
* Плавная деградация (отказоустойчивость): если PostgreSQL недоступна, бот переключается в режим in-memory

**Примечания**

* Этот проект имеет модульную структуру по функциональным областям: commands (команды) -> handlers (обработчики) -> services (сервисы) -> utils (утилиты)
* bot.js является единым источником истины (single source of truth) для тем/цветов эмбедов и базовой конфигурации бота
* Кэширование Redis реализовано для статистики сервера, данных экономики и ограничения скорости запросов (rate limiting)
* Дашборд предоставляет современный веб-интерфейс для управления ботом
* У нас может быть реализовано не все, что указано в roadmap.txt, или могут присутствовать новые функции, не упомянутые в roadmap.txt
