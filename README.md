# ЭтерисBot - Ультра-модульный Discord Bot

**ЭтерисBot** — это мощный, функциональный Discord bot, созданный для улучшения опыта в сервере через комплексные инструменты модерации, увлекательные системы экономики, утилиты и многое другое. Разработан на современном Discord.js v14 для обработки интеракций и PostgreSQL для хранения данных.

## Обзор функций

- **Модерация & Администрирование**: Массовые действия, заметки пользователей, управление делами
- **Система экономики**: Магазин, азартные игры, платежная система
- **Развлечения & Утилиты**: Случайные факты, переворот текста
- **Система тикетов**: Расширенное управление тикетами с сохранением протоколов
- **Мониторинг статистики**: Счетчики участников, статистика голосовых каналов
- **Система уровней**: Отслеживание XP, уровневые роли
- **Розыгрыши**: Поддержка нескольких победителей, автоматический выбор победителей
- **Объявления о днях рождения**: Уведомления с учетом часовых поясов
- **Инструменты управления**: Система жалоб, списки дел
- **Система приветствия**: Персонализированные встраивания, автоматическое присвоение ролей

## Кеширование

Для повышения производительности ЭтерисBot использует PostgreSQL для кеширования часто запрашиваемых данных, таких как статистика серверов, логи и модули. Это уменьшает нагрузку на основные запросы к базе данных и ускоряет отклик веб-интерфейса.

## Быстрая настройка

### Развертывание на Railway

1. Установите переменные окружения в панели Railway:
   - `DATABASE_URL` (обязательно, подключение к PostgreSQL)
   - `BOT_TOKEN` (токен вашего Discord бота)
   - `CLIENT_ID` и `CLIENT_SECRET` (для OAuth2, если используете веб-панель)
   - `PORT` (опционально, по умолчанию 3000)
   - `NEXT_PUBLIC_BOT_API_URL` (опционально, по умолчанию /api)

2. Railway автоматически обнаружит ваш Dockerfile и запустит сборку.

### Безопасность (Самообслуживание)

- Регулярно обновляйте зависимости.
- Используйте переменные окружения для секретных данных.
- Ограничьте доступ к базе данных только доверенными IP-адресами.
- Включите логирование и мониторинг аномалий.
